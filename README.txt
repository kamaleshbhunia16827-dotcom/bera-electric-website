BERA ELECTRIC — Revised single-page website

FILES
- index.html: complete single-scroll homepage
- style.css: responsive layout and visual styling
- script.js: 4-banner slider, mobile menu, quotation-to-WhatsApp form
- assets/: supplied banner images plus a generated transformer installation visual

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. For hosting, upload the complete folder contents to your hosting service/GitHub repository, keeping the assets folder beside index.html.

IMPORTANT
- The quotation form opens WhatsApp with the customer's details. It does not save form submissions to a database.
- Confirm the email spelling and all licence/WBSEDCL claims before publishing.
- The uploaded pole banner was supplied twice; both files are retained as separate slider assets because they were provided as separate banner images.
